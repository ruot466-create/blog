# 我用什么

这里记录我目前使用的软件，以及这个博客背后的工具。随着学习和使用习惯变化，这份清单也会慢慢更新。

## 编辑与命令行

- **[Visual Studio Code](https://code.visualstudio.com/)**：编辑代码和 Markdown 文档。
- **Windows PowerShell**：运行命令、启动本地服务，以及执行构建和部署脚本。
- **DSH**：这个博客的搭建和调整助手。从页面到互动功能，很多改动都是借助它完成的。
- **Codex**：协助检查博客、整理内容、调整页面和验证改动。

## 开发与版本管理

- **[Node.js](https://nodejs.org/)**：运行这个博客所需的开发工具。
- **[pnpm](https://pnpm.io/)**：管理项目依赖，启动本地预览和构建网站。
- **[Git](https://git-scm.com/)**：保存代码修改的历史，方便查看差异和回退。
- **[GitHub](https://github.com/ruot466-create)**：存放源码，也为博客评论提供支持。

## 这个博客

- **[Astro](https://astro.build/)**：网站框架，把文章和页面构建成静态网站。
- **[Fuwari](https://github.com/saicaca/fuwari)**：博客使用的主题，提供文章列表、归档、分类和标签等基础界面。
- **Markdown**：文章的写作格式，用纯文本组织标题、段落、链接和图片。
- **Cloudflare Workers**：网站的部署平台。
- **[Pagefind](https://pagefind.app/)**：站内搜索，帮助查找已经发布的内容。
- **[Giscus](https://giscus.app/zh-CN)**：文章评论，使用 GitHub 账号参与讨论。

## 可以逛逛的地方

- **[文章归档](/archive/)**：按时间查看发布过的文章。
- **[吉他小工具](/guitar/)**：拨弦、试听和弦，或者打开伴奏和节拍器练习。
- **[RSS 订阅](/rss.xml)**：用阅读器订阅博客更新。
- **[博客源码](https://github.com/ruot466-create/blog)**：查看这个网站的代码。
